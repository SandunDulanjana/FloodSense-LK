M1 Flood-Exposure Demo (J26-DS-360, IT23401112)
================================================
Option A (simplest): double-click index.html  -> opens in Chrome/Edge (works offline).
Option B (local web server, "localhost" demo): double-click run_demo.bat
          -> opens http://localhost:8000/index.html  (needs Python installed).
Keep the "assets" folder next to index.html. Use Chrome or Edge (WebGL needed).
Map: scroll to zoom, drag to pan, hover/click a building for details.

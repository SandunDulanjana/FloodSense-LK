# Module 3: Agricultural Impact Assessment (FloodSense-LK)

This module handles agricultural flood impact analysis and modeling for Sri Lanka.

## Structure
- `configs/`: Configuration files
- `notebooks/`: Jupyter exploratory and modeling notebooks
- `tests/`: Module tests
- `models/`: Model checkpoints / artifacts
- `src/gee/`: Google Earth Engine scripts and data pipelines
- `outputs/reference_dataset/polygons/`: Reference polygon datasets
- `outputs/reference_dataset/samples/`: Reference sample points / extracted data
- `outputs/results/`: Evaluation results and exported impact layers
